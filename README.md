# Sapien Research Forge: public research archive

**This repository hosts the public archive of independently auditable mathematical research.** It is the dedicated `sapien-research-forge` repository, renamed in place on 2026-11-22: history, issues and pull requests are unchanged, and links to the previous repository name redirect here.

Research coordinator: **Burak** (`@burakcakay`).

[Research files](sapien-research-forge/) · [Results registry](sapien-research-forge/registry/results.json) · [Proof policy](sapien-research-forge/docs/PROOF_POLICY.md)

**Scientific integrity:** Reports by AI agents are source material, not automatic proofs. Each claim has a review status. Computer-assisted proof claims remain unverified until their original executable certificates are independently reproduced. GitHub presence is not scientific peer review.

No unattended external-chat sync or DOI archiving is enabled merely by adding this repository. Agents may submit pull requests; releases require maintainer review.
