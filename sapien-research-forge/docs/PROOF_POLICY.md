# Scientific claim review policy

A model's PROVED label, another model's agreement, and a high-precision numerical run are not equivalent to proof.

- CONJECTURE: falsifiable speculation with clear scope.
- NUMERICAL: finite calculations with stated numerical precision.
- ANALYTIC_PROOF_CANDIDATE: human-readable proof awaiting independent review.
- CAP_PENDING_REPRODUCTION: claimed interval computer-assisted proof missing independent executable reproduction.
- INDEPENDENTLY_VERIFIED: independent reviewer verified exact statement and evidence.
- FORMAL: a checked theorem in named proof assistant with exact proof artifact.
- REFUTED: explicit counterexample to the stated hypotheses.

GitHub CI covers syntax, source presence, and simple identities, not mathematical correctness.

Release/DOI requires human approval and a novelty/literature review. No auto-merging or automatic proof-status promotion. Preserve corrections instead of silently rewriting records.
